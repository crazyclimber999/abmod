# Each one is diverted at install time, so the upstream file is kept beside it
# as <name>.openwebrx-original and comes back when ABMod is removed. Without a
# diversion dpkg would refuse to unpack over another package's file, and a
# later openwebrx upgrade would silently overwrite the modification.
#
# Paths are relative to /usr/lib/python3/dist-packages.
# Regenerate with packaging/list-diverted.sh against a receiver that has a
# pristine openwebrx installed.
