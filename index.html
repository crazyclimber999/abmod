ABMod APT repository

Modifications to OpenWebRX, installable with apt-get.

ABMod adds to OpenWebRX a bookmarks panel inside the receiver, real access control, 5-tone and 2-tone decoders, a map drawn without the Google Maps API, APRS in both directions, and an importer for a repeater list that works out from the terrain which stations are actually receivable.

Adding the repository

sudo curl -fsSL https://crazyclimber999.github.io/abmod/abmod-archive-keyring.asc \
  -o /usr/share/keyrings/abmod.asc
echo "deb [signed-by=/usr/share/keyrings/abmod.asc] \
https://crazyclimber999.github.io/abmod/ bullseye main" \
  | sudo tee /etc/apt/sources.list.d/abmod.list
sudo apt-get update && sudo apt-get install abmod

Before you install it

ABMod replaces 31 files belonging to the openwebrx package, through dpkg diversions: the original is kept beside its replacement and apt-get remove abmod puts it back. Two consequences worth knowing in advance.

It refuses to install over an ABMod put there by hand, and names the files. Run sudo apt-get install --reinstall openwebrx first — that touches no settings, bookmarks or users — then install the package.

OpenWebRX is held at the version ABMod was built against. Whole files are replaced rather than patched, so a different OpenWebRX is a different set of files. To upgrade OpenWebRX, remove ABMod first.
